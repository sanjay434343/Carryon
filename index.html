FAQ

Frequently Asked Questions

Everything you need to know about Carryon.

Is Carryon completely free and open source? +

Yes! Carryon is 100% open source under a permissive license. You can inspect, fork, and contribute to the source code anytime on our GitHub repository at github.com/sanjay434343/Carryon.

How does the Google Sheets integration work? +

Carryon connects through a lightweight Flask backend API service that fetches public Google Sheet data in real-time. The data is cached intelligently for instant access both online and offline.

Which platforms does Carryon support? +

Carryon is built with Flutter, currently supporting Android builds out of the box. Desktop (Windows, macOS, Linux) and web builds are on the roadmap for upcoming releases.

What is MTProto and why does Carryon use it? +

MTProto is Telegram's custom cryptographic protocol designed for speed and security. Carryon leverages MTProto for ultra-fast, encrypted communication with Telegram's infrastructure, ensuring your cloud sessions are both instant and private.

How secure is Carryon? +

Extremely secure. Carryon implements AES-256 encryption for data at rest, two-factor authentication for login flows, and tokenized session management. Your files never leave your device unencrypted.
